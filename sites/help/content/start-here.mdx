## Players

Sign in on your own device and explore your team and game information. Your
account’s permissions determine which actions appear; being a player does not
by itself grant editing or broadcasting access.

<Steps>
<Step>
### Sign in

Use the [email-code guide](/en/sign-in). Never share the code.
</Step>
<Step>
### Find the event and game

Use [Games inside an event](/en/following-a-game) to view available details.
</Step>
<Step>
### Set up your device

Review [installation](/en/install) and [notifications](/en/notifications).
</Step>
</Steps>

## Organisers

Start with the same sign-in and event navigation guides. If you expect to manage
an event but the action is missing, check your account’s assigned permissions
with the organisation. This help preview does not document unverified admin or
broadcast workflows.

<Callout title="Permissions matter">
Opening an event or following a team does not grant permission to edit or broadcast.
</Callout>
