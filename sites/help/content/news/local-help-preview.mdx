## What is available

The local help preview provides guides for sign-in, finding games, team follows,
notifications and installation. It includes full-text search, explicit Markdown
exports, a sitemap and generated social images.

The help package has its own dependencies and build. Authors can keep the Vite
server running while editing content and see their browser update.

## Release scope

This note records a local documentation milestone. It does not announce a new
Remy Sport app release or promise public availability. The preview remains noindex.
Thai and Japanese translations are local drafts awaiting human language review.
